# Luna Frontier 2.0 Preview 4

2026年9月14日、Luna Frontier Preview 4を公開します。

今回のPreviewでは、ヘッダー直下のSPOTLIGHT・特集・おすすめ・カテゴリを1段に統一し、ガジェットをおすすめから除外しました。SPOTLIGHTの省略記号は新設したスポットライトアーカイブへの導線になり、アーカイブでは先頭だけを大きく扱わず、すべての特集を同じカードで表示します。

本番から5特集、関連記事21件、アイキャッチ14点をローカル検証環境へ取り込みました。Lunaは引き続きNodeを親テーマとするPreview版です。

## 配布物と導入

- `node.zip`: Node本体の同梱ビルド。
- `luna-frontier.zip`: Luna Frontier `2.0.0-preview.4`。ZIP内ルートは `luna-frontier/`。
- 配布ブランチは `luna-frontier-2.0-skyalow`、タグは `luna-frontier-v2.0.0-preview.4` です。
