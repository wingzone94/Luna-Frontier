# ヒーロータイトル領域の分離案（N39 / N1）

画像内とオーバーレイのタイトルが同じ位置にある場合、両方の文字が重なる。オーバーレイのタイトルを省略・非表示にしないことを前提に、次の案を比較する。

## 案A: 左側グラデーション帯（推奨）

タイトル領域の左側に暗いグラデーションを置き、画像の右側に向けて透明にする。帯の下端は徐々に薄くし、画像下部に書かれた情報を見せる。タイトルは白のまま維持する。

- 現在の構成と配置を活かせる。画像左側の文字は暗くなるため、完全に読めることは保証できない。
- PC とモバイルで帯の範囲を調整し、画像下部の情報とタイトルのコントラストを検証する。
- T1 のドラフト #114 と同じ CSS を変更するため、統合時に差分を調整する必要がある。

## 案B: タイトル専用の半透明パネル

タイトル、カテゴリ、日付をまとめて半透明パネルに載せる。パネル外の画像は見えやすくなるが、パネルの直下の文字は隠れる。パネル自体の面積や画像の視認性に影響する。

## 案C: タイトルを画像外に配置

画像とタイトル領域を分け、両方を遮らない構成にする。画像文字の可読性を優先できる一方、ヒーローの構成と高さが大きく変わる。

## 検証条件

1920px と390pxで文字入り画像、画像なし、長いタイトル、複数スライドを確認する。タイトルと画像文字、CTA、ページ送りの可読性と、横はみ出しや操作可能領域を検証する。実画像の文字の配置によっては、案A・Bともに重なりを完全には防げない。
