WordPressプラグイン「Luna interactive」。ブロック名は「グラフ」です。
Node 1.4.0には同梱されています。単独版が有効な場合は単独版が優先されます。

== インストール・更新 ==
1. WordPress管理画面の「プラグイン → 新規プラグインを追加 → プラグインのアップロード」でZIPを選びます。
2. 既存のLuna interactiveがある場合は、アップロードしたプラグインで置き換えます。
3. 有効化後、投稿編集画面で「グラフ」を追加します。
内部のブロック識別子 luna-interactive/chart は維持しています。0.1.0の記事はそのまま読み込めます。
キャッシュプラグイン/CDNを利用している場合、更新後に対象ページのキャッシュを消してください。

== 編集 ==
・CSV/XLSX/XLSを読み込みます。先頭行は見出し、先頭列は項目名、2列目以降は数値系列です。
・CSVはUTF-8またはShift_JISを選べます。引用符内のカンマ・改行・二重引用符に対応します。
・Excelでは読み込んだブックのシートを選択できます。
・「データを編集」で項目名、系列名、数値を変更し、行・系列を追加／削除できます。25行ずつ表示します。
・空欄、N/A、NA、null、—、- は欠損値です。0とは区別します。
・数値の桁区切り、負数、小数、指数表記に対応します。通貨記号や%付き文字列は数値へ直してください。
・最大5MB、1,000データ行、棒・折れ線のみは20系列、円を公開形式に含む場合は5系列、数値は±1,000兆です。上限超過はエラーにし、黙って切り捨てません。
・入力エラー時は元の数値を保持し、投稿エディターでは保存をロックします。訂正すると解除します。
・タイトル・説明はプレーンテキスト。出典名と出典URLを別々に設定できます。
・棒・折れ線・円グラフ、高さ、公開時の初期ビューを選べます。
・日付による絞り込みを使う場合、項目名をYYYY-MM-DDにしてください。

== 公開ページ ==
・編集画面で棒・折れ線・円から公開できる形式を1～3種類選べます。既存のグラフは3種類すべてを許可します。
・1種類だけ許可した場合、公開ページには形式切り替えを表示しません。
・タイトルと補足の下に、グラフを大きく表示します。
・棒・折れ線・円と、動的・静的は、グラフ内のアイコンで切り替えます。名称はボタンのラベルとして読み上げます。
・系列はチップで表示・非表示を切り替えます。複数系列の円グラフでは各系列の円を並べ、系列と項目の表示を別々に切り替えます。円グラフの凡例はグラフの下に表示します。棒・折れ線では広い画面の右内側、スマホ幅の「凡例」メニューに表示します。
・円グラフの動的表示はChart.jsのCanvasで描画します。負数・欠損値は円の計算から除外します。
・PCで動的な円グラフの円弧にホバーすると、その系列の表示中の項目合計を100%とした割合を表示します。スマートフォンでは表示しません。
・グラフ形式の切り替えは閲覧中の表示だけです。保存された初期形式は変わらず、再読み込みで戻ります。
・公開ページの動的描画はChart.jsのCanvasです。系列や形式の切り替えはCanvasに反映されます。
・静的ビューは現在のCanvasをWebP（品質0.95）へ変換します。非対応ブラウザーではPNGになります。
・静的画像はブラウザー内で生成し、メディアライブラリや記事本文へ保存しません。
・初期HTMLには最新データから生成したSVGグラフを含めます。JavaScript無効時や描画失敗時も参照できます。
・円グラフの複数系列は系列ごとに塗りつぶしの円を並べて表示します。円を公開形式に含める場合、新規・再編集時の系列上限は5です。既存の6系列以上の公開データは削りません。負数・欠損値は円の計算から除外します。凡例には系列と項目を分けて表示します。
・複数グラフの操作は互いに独立しています。
・Luna Frontier / Node の --md-sys-color-* と data-theme を優先します。トークンが無いテーマでは、ライトはクリームとオレンジ、ダークはブラウン／チャコールと明るいオレンジにフォールバックします。系列色はブランドオレンジとは別の配色です。
・OSのダークモード、または html の data-theme="dark" / "light" に合わせてカード・文字・グラフを調整します。

== コピー抑止 ==
公開グラフ全体で文字選択、コピー／切り取り、コンテキストメニュー、画像ドラッグを抑止します。
公開グラフのfigureには `data-luna-copy-protected="true"` を付け、この属性を対象に抑止します。
編集画面の数値入力は維持します。
これは操作上の抑止でありアクセス制御ではありません。スクリーンショット、開発者ツール、HTML取得を防ぐ機能ではありません。
データは公開HTMLに含まれます。機密情報は入力しないでください。

== 依存ライブラリ ==
Chart.js 4.4.3 (MIT、編集画面のプレビューと公開グラフ用) / SheetJS CE 0.20.3 (Apache-2.0)
ライブラリを同梱し、通常の閲覧・編集で外部CDNへ接続しません。
著作権・ライセンスは assets/vendor/ 内を参照してください。
