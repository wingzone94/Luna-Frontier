# Luna AI Tools

通常のAI接続先はOllamaが既定です。モデルの既定は `gemma3:4b`。接続先サーバーにモデルが導入されていることを「接続テスト」で確認してください。保存済みの接続先・モデルは自動で上書きしません。CPU上のローカル推論は数分かかる場合があり、Ollamaとローカル互換プリセットは最大600秒待ちます（クラウド互換プリセットは180秒）。Webサーバー側の実行時間制限は別途適用されます。ローカル校正は1回最大3件に絞ります。修正後に再実行して段階的に確認してください。

「OpenAI互換」はローカルOllamaの `/v1`、OpenAI、DashScope、任意のChat Completions互換サーバーに対応します。プリセットは空欄のURL・モデルの既定値を指定し、入力済みの値を消しません。OpenAI・任意サーバーでは使用するモデルIDを入力してください。ローカル接続ではAPIキーは任意です。クラウドの料金・モデル可用性は提供元の設定を確認してください。

設定名は `node_ai_openai_preset` / `node_ai_openai_endpoint` / `node_ai_openai_model` / `node_ai_openai_api_key`。キー欄を空欄で保存すると既存値を保持し、削除チェックでのみ消去します。設定変更・接続テストにはWordPress管理者権限とnonceが必要です。

旧 `qwen` 選択は更新時に `openai` へ移行します。新設定がまだない場合だけ、旧接続先・モデル・キーを組としてコピーし、DashScopeプリセットを使います。新設定が一つでもあれば混ぜません。旧 `node_ai_qwen_*` optionと `Node_AI_Provider_Qwen` クラスは互換経路として残します。利用履歴にはプロンプト・キーを保存しません。

Ollama標準APIとOpenAI互換APIそれぞれの接続・生成を確認できます。API/モデルの差異でJSONや画像入力を受け付けない場合は、対応するモデルを選んでください。Gemma 3 4Bは画像対応です。Qwenの既存指定は保持しますが、検証環境のQwen 3 4BではJSON生成時の反復エラー・タイムアウトが発生したため、既定モデルには採用していません。

配布元は `plugins-embedded/node-ai-tools` の単一ソースです。検証後に `scripts/build-ai-tools-zip.sh` で単体ZIPを生成します。既存の単体プラグインが有効な環境ではそちらを優先します。


## ファクトチェック

専用の `node_ai_fc_provider` は全体の接続先と独立し、既定はGeminiです。記事の編集画面では今回の実行に限ってGemini / Ollama / OpenAI互換を選択できます。この選択は全体設定や自動実行の既定を変更しません。「使用しない」は全AIを停止します。

Geminiは既存の無料枠モデル選択・Google Search Grounding・上限・検索必須ポリシーを利用します。有料モデルへの自動切り替えはしません。検索できなかった結果にはその条件を記録します。Ollama / OpenAI互換は「検索なし・モデル知識とガイドライン照合のみ」で、外部根拠の自動収集も行いません。小型モデルでは本文先頭1500字・ガイドライン先頭750字・主張最大3件を対象にし、範囲を表示します。記事全体を調べた結果として扱わないでください。

検索なしの応答に含まれるURLは確認済み根拠として保存しません。基礎前提キャッシュはプロバイダ・モデルごとに分離します。保存結果・公開表示・利用履歴に実行条件を残し、検索なしを選んだ結果は後から自動でGeminiへ切り替えて再実行しません。自動再実行の対象はGeminiの検索枠が不足した結果だけです。


## 画像alt

alt生成は共通の `Node_AI_Core::analyze_image()` を使います。JPEG / PNG / WebP（10MB以下）の実ファイルを検証し、必要な場合のみ送信用に最大768pxへ縮小します。元画像は変更しません。Ollamaはメッセージのimages、OpenAI互換は画像データURLで送信します。画像対応モデルを選んでください。画像非対応や生成失敗時はエラーを残し、別のGemini接続へ自動切り替えしません。

保存時の自動生成設定は全体の接続先と共通です。生成済み・人が書いたaltを上書きせず、推論中に手入力されたaltも保持します。生成画像データ・プロンプトは利用履歴に記録しません。旧Gemini APIクラスのanalyze_imageも互換入口として共通基盤へ委譲します。

Gemini設定ヘルパーの利用先を調査し、altの直接呼び出しを撤去しました。残る利用先はプロフィール／モデル設定、Intelligence SummaryのモデルUI、ファクトチェックのキー・無料枠選択、および共通Geminiアダプタです。現ツリーにはTTS実装ファイル・Gemini TTS呼び出しは見当たりません。適用範囲のガードと専用設定の整理はA4で実装します。
